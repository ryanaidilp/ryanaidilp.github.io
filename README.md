# Resume and CV (static site)

Two static pages for GitHub Pages: `index.html` (short resume) and `cv.html` (full CV with projects and publications).
No build step, no dependencies. `style.css` has a dark mode and an A4 print stylesheet (use the browser's Print, Save as PDF).

## Deploy to GitHub Pages (no Actions minutes)
1. Create the repo `ryanaidilp.github.io` (user site) or any repo, push these files to `main`.
2. Repo Settings, Pages, Source: "Deploy from a branch", Branch `main`, folder `/ (root)`.
3. Open `https://ryanaidilp.github.io/` (or `/<repo>/`).
